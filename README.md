# QSniper

Локальная версия скрипта для автозаписи в FunAndChecks.

## Запуск с рабочего стола

Открой ярлык **QSniper**:

1. **Проверка без записи** — входит на сайт, показывает почту аккаунта, текущие личные очереди со статусами и очереди, подходящие для новой записи. Статус «завершил сдачу» означает завершение в очереди, а не обязательно зачёт лабораторной. Никого никуда не записывает, возвращается в меню после одной проверки.
2. **Автозапись** — проверяет очереди каждые 5 секунд и записывается в первую подходящую. После успеха подаёт сигнал и завершает работу.

После проверки и завершения автозаписи программа возвращается в главное меню. Ctrl+C останавливает текущую операцию и возвращает в меню; пункт 0 закрывает программу.

3. **Посмотреть / изменить почту и пароль** — показывает сохранённые почту и пароль открытым текстом. Внутри: 1 — изменить данные, 0 или Enter — вернуться в главное меню. Вход запоминается между режимами и перезапусками. Если данные ещё не сохранены, пункты 1 и 2 предложат ввести их. При вводе нового пароля символы не отображаются.
4. **Изменить интервал проверки** — пауза между циклами в секундах, минимум 1 секунда. Допускаются `2,5` и `2.5`. Значение сохраняется между запусками; по умолчанию 5 секунд. Время сетевых запросов добавляется к паузе, поэтому это не гарантия точного периода. При ошибках или ограничениях сервера ожидание может быть больше. Как только очередь обнаружена, запрос записи отправляется сразу.
5. **Послушать сигнал успешной записи** — воспроизводится тот же файл, который звучит при записи: три коротких сигнала по 250 мс, 1200 Гц, с паузами 80 мс.
6. **Удалить сохранённые данные входа** — убирает локально сохранённый аккаунт.

Настройки находятся в `%LOCALAPPDATA%\QSniper`: `settings.json` содержит интервал, `account.bin` — зашифрованные почту и пароль. Шифрование Windows DPAPI привязано к текущему пользователю Windows. Данные не лежат в репозитории, пароль не передаётся в аргументах запуска. Сохранение само по себе не проверяет пароль — для этого запусти пункт 1. Прямой запуск `queue_sniper.py` из PowerShell продолжает спрашивать вход отдельно; сохранённые настройки применяются через меню `launch.py` и ярлык.

В ярлыке настроен фильтр: **предмет №2 ИЛИ название содержит «криптограф»**, без учёта регистра. Если название станет просто датой, очередь всё равно подойдёт по номеру предмета. Если создадут новый предмет с другим номером, но сохранят слово «криптограф» в названии очереди, сработает текстовая проверка. Если изменят и номер, и название, фильтр потребуется обновить.

Очереди без самостоятельной записи и очереди, где пользователь уже записан, пропускаются. Подходящая очередь может существовать ещё до запуска. Время записи влияет на порядок только при равных баллах; первое место не гарантируется.

Для ожидания оставь окно открытым и компьютер включённым, без сна. Остановка — **Ctrl+C**. Автозапуска в фоне нет.

## Запуск из PowerShell

```powershell
cd C:\QSniper
py -X utf8 queue_sniper.py --site https://funandchecks.ru --subject-id 2 --match "криптограф" --check
```

Для настоящей автозаписи убери `--check`. По умолчанию работа прекращается после первой записи; `--keep` продолжает ожидать следующие очереди.

Без `--subject-id` и `--match` выбирается любая доступная очередь. Если заданы оба параметра, между ними действует **ИЛИ**. Текстовое совпадение может выбрать другой предмет с похожим названием; для строгой проверки только номера используй один `--subject-id 2`.

При временном отказе записи 403/404 скрипт повторно проверяет доступность на следующем цикле. При сетевых ошибках увеличивает паузу до минуты. При запросе сервера 429 соблюдает Retry-After.

Обычные команды `python` на этом компьютере указывают на неработающий псевдоним Windows; используй `py` или ярлык.
